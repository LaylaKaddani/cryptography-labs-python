# cryptography-labs-python


Collection of cryptography practical labs completed during my
engineering studies.

The repository focuses on implementing and analyzing cryptographic
concepts using Python, with an emphasis on understanding the
underlying mechanisms rather than treating cryptography as a black box.

Topics covered:

- Pseudo-random number generation
- Symmetric encryption
- Stream ciphers
- XOR-based constructions
- Encoding and binary data handling
- Key management concepts
- Network communication with TCP sockets
- Cryptographic protocols
- Security analysis and limitations

Each lab contains its own documentation, source code and usage
instructions.

Cryptographic primitives implemented in the labs should not be
considered production-ready security mechanisms unless explicitly
stated otherwise.
